# Shulker Insight

Клиентский мод для Minecraft: показывает содержимое шалкера во всплывающей подсказке, индикатор заполнения и единый значок/иконку предмета.

Клиент не получает содержимое установленного закрытого шалкера, пока его не откроют. Поэтому значок в мире появляется только после первого открытия шалкера в текущей сессии.

## Разработка

```sh
direnv allow
./gradlew build
./gradlew test
./gradlew runClient
```
